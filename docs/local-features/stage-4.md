# Четвёртый этап: LF-22 и LF-23

Этап добавляет раскрытие компактных меток папок возле чата и переносимые
настройки навигации. Основа LF-03 остаётся единственным источником членства:
`navigation_preferences` содержит только ссылки и порядок отображения.

## Реализовано в Desktop

- Нажатие на нативную метку `+N` в строке чата открывает список всех
  применимых папок; пункты используют текущие названия и переходят в выбранную
  папку. Список строится из `ChatFilter::inChatList`, поэтому переименование,
  удаление, правила, цвет и членство обновляются через существующий поток
  `chat_folders`.
- Локальный модуль `navigation_preferences` версии 1 хранит аккаунтные
  `startup_ref`, `last_section_ref`, `restore_last_section` и `visible_order`.
  Локальная ссылка имеет вид `local:<folder UUID>`, облачная ссылка —
  `filter:<numeric id>:<incarnation UUID>`, а All Chats обозначается `all`.
  Временные отрицательные `FilterId` в переносимый JSON не записываются.
- При недоступной стартовой или последней ссылке выбирается All Chats, исходная
  ссылка остаётся в модуле для последующего разрешения. Порядок применяется к
  общему списку фильтров, поэтому вкладки, мышь, Vim и цифровые команды
  используют один разрешённый порядок.
- Выбор папки в штатной полосе вкладок запоминает её как стартовую и последнюю
  секцию; политика восстановления последней секции остаётся отдельным полем
  модуля и может быть изменена настройками следующего слоя.

## Границы доказательств

Исходная проверка подтверждает регистрацию модуля, валидацию схемы и компиляцию
затронутых исходников. Она не подтверждает запуск установленного клиента,
экспорт/импорт на реальном аккаунте, Android/QR-перенос или пользовательскую
приёмку; эти слои проверяются отдельно после сборки этапа.
