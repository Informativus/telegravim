# Android app name and icon

The Televim Standalone APK is named **Televim** and uses Telegram's original
launcher icon, adaptive icon background and launch splash from the pinned
`android/upstream` source. The overlay no longer replaces these resources, so
all six launcher aliases, their settings previews and Android 12's launch
splash come from upstream unchanged. Upstream assets and their licenses remain
intact in `android/upstream`.

The app name comes from the reviewed string patches. A different icon would be
a separate, explicit branding change.
