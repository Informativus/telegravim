# Руководство Telegravim

Telegravim добавляет Vim-навигацию в Telegram Desktop. Ниже описаны режимы,
основные действия, редактор JSON и все 37 настраиваемых параметров.
Сочетания в разделе управления приведены для стандартной конфигурации.

## Режимы и управление

### Чат и ввод

В режиме ввода буквы печатают текст. Esc переводит в режим просмотра;
в нём доступны команды навигации. Команды редактора сообщения `i` и `a`
возвращают к вводу перед символом и после него. Cmd+V на macOS остаётся
вставкой, а физический Ctrl+V показывает метки предпросмотра чатов.

- `j` / `k`: прокрутка активного чата или содержимого открытого окна.
- `Ctrl+J` / `Ctrl+K`: следующий или предыдущий чат.
- `Tab` / `Shift+Tab`: следующая или предыдущая папка; в модалке это обход
  доступных элементов интерфейса по кругу.
- `Ctrl+G`: действие нижней угловой кнопки чата, включая возврат по переходам.
- `/`: поиск в текущем чате; `Ctrl+F`: глобальный поиск.
- `Ctrl+H` / `Ctrl+L`: назад и вперёд в поддерживающих это окнах;
  в медиапросмотрщике это навигация между объектами.
- `?`: краткая справка и журнал клавиш для диагностики.

### Метки и сообщения

После команды нажмите метку нужной цели. Сначала используются однобуквенные
метки; несколько букв появляются лишь при нехватке коротких. Esc отменяет метки.
Метки ограничены текущим окном, чтобы не активировать фон под модалкой.

| Команда | Действие |
| --- | --- |
| `f` | Метки ссылок, медиа и элементов интерфейса. Кнопка получает фокус; Enter выполняет её действие. |
| `o` | Метки чатов для обычного открытия. |
| `Ctrl+V` | Метки чатов для предпросмотра без отметки о прочтении. |
| `Ctrl+Shift+V` | Выбор сообщения для перемещения по его тексту без ввода. |
| `r` | Выбор сообщения для ответа. |
| `e` | Выбор собственного сообщения, доступного для редактирования. |
| `d` | Выбор сообщения для удаления с обычными проверками Telegram. |
| `s` | Выбор сообщения для пересылки. |
| `y` | Копирование выбранного сообщения или фотографии. Ограничения чата сохраняются. |

### Текст и visual

Пока показаны метки выбора, буквы выбирают сообщение: например, `d` выбирает
метку `d`, а не включает удаление. Можно выбрать и подпись к фотографии;
сообщения без текста не получают метку выбора текста.
После выбора текстового сообщения курсор сначала только перемещается.
`h` / `l` двигают по символам, `w` / `b` по словам.
`j` / `k` двигают вниз / вверх по строкам (`о` / `л` в русской раскладке).
`Shift+J`, `Shift+K` и `Shift+H` сохраняются как дополнительные сочетания.
`v` включает выделение; повторное `v` не должно убирать курсор. `viw` выделяет
слово. `|` и `/` переходят к началу строки, `$` и `;` к концу.
`{` / `}` переходят к началу предыдущего / следующего абзаца (по переносам
строк, пропуская пустые строки). `gg` идёт к началу выбранного сообщения,
`Shift+G` — к концу; в visual эти команды расширяют выделение.
`y` копирует выделение, сохраняя его и курсор. Неподдерживаемые клавиши ничего
не меняют и не запускают команды чата. Только `Esc` снимает выделение, а затем
выходит из текстового режима. Команды работают и в русской раскладке.
Этот режим не изменяет отправленный текст.

### Вложенные окна и медиа

Tab и Shift+Tab обходят доступные кнопки, чекбоксы и вкладки. Enter нажимает
выбранный элемент. У ползунка Enter включает изменение значения через h/l;
Tab продолжает обход. Esc сначала закрывает вложенное меню или предпросмотр,
а затем основное окно. В контекстном меню j/k используют тот же выбор, что Tab.

Голосовые сообщения и кружки, выбранные через f, запускаются встроенным
проигрывателем. В просмотрщике видео d увеличивает скорость на 0,1,
a уменьшает на 0,1, q возвращает 1x. Эти клавиши зависят от контекста:
например, d в чате выбирает сообщение для удаления.

В окне стикерпака j/k перемещают выбор, Ctrl+J/Ctrl+K прокручивают содержимое.
Enter отправляет выбранный стикер, w открывает его увеличенный предпросмотр.
Esc из этого предпросмотра не закрывает сам стикерпак. Кнопки добавления,
удаления и меню доступны через Tab и Enter.

## Установка и обновление

На macOS используется Release-образ `Telegravim.dmg`. Закройте клиент сами,
откройте образ и замените приложение в Applications. Проверьте номер сборки,
чтобы не запускать старую копию. Не удаляйте папку данных Telegram: JSON
настроек Vim не является резервной копией аккаунта или переписки.

## UI и JSON

Откройте «Настройки → Vim keymap». UI и JSON редактируют один набор настроек,
общий для аккаунтов этой установки Telegram. Отдельного режима исполнения
JSON нет. Настройки сохраняются штатным локальным механизмом Telegram;
серверу они не передаются, перезапуск для применения не нужен.

- **UI**: привычные переключатели и строки параметров. Изменения сохраняются сразу.
- **JSON**: текстовый редактор с полным снимком текущих значений, включая значения
  по умолчанию и отключённые сочетания. Сам ввод текста ничего не применяет.
- **Применить**: проверяет весь JSON и только после успешной проверки обновляет
  настройки. Неизвестные ключи, неверные типы, диапазоны и сочетания отклоняют
  весь документ. Ошибка показывает ключ либо строку и столбец; текст остаётся в редакторе.
- **Перечитать**: загружает действующие значения. При наличии правок запрашивает
  подтверждение их отбрасывания. Это не сброс к заводским значениям.
- Руководство хранится отдельно в `docs/vim-keymap.md` и Wiki проекта;
  внутри настроек нет окна с руководством.
- Переключение из JSON в UI, кнопки назад/закрыть и Esc не должны молча терять
  правки: подтвердите их отбрасывание либо вернитесь и нажмите «Применить».
  Принудительное завершение процесса не сохраняет черновик JSON.
- Если настройки изменены в другом окне во время редактирования JSON,
  применение останавливается. Скопируйте нужный текст, перечитайте действующие
  значения и внесите изменения заново, чтобы не перезаписать чужие правки.

## Формат

В корне находится обычный JSON-объект. Ключи совпадают с идентификаторами
настроек и чувствительны к регистру. Допустимы только ключи из справочника ниже.
Пропущенный ключ сохраняет действующее значение; `{}` ничего не сбрасывает.
`null` не означает сброс и не принимается. Для возврата параметра к стандартному
значению укажите его значение по умолчанию из справочника.

Комментарии, завершающие запятые, JSONC и JSON5 не поддерживаются. Не повторяйте
ключи: стандартный парсер Qt сохраняет последнее значение повторённого ключа.
Максимальный размер документа: 64 КиБ UTF-8. Внутренний маркер миграции
`vim-keymap-defaults-migrated` не является пользовательским параметром и в JSON
не допускается. Остальные экспериментальные настройки импорт не затрагивает.

Рядом с этим документом в репозитории находятся `vim-keymap.example.json`
(полный стандартный конфиг) и `vim-keymap.schema.json` (типы, диапазоны,
описания и значения по умолчанию). Схема не исполняет команды и не загружается
из сети. Приложение дополнительно проверяет синтаксис сочетаний клавиш.

## Сочетания клавиш

Все ключи `vim-keymap-key-*` принимают строку длиной до 1024 символов.
Несколько вариантов разделяются запятыми, например `"j, о"`.
Пустая строка `""` отключает конкретную настраиваемую команду.
Пробелы вокруг частей и регистр записи несущественны.

Модификаторы: `Ctrl`/`Control`, `Cmd`/`Command`/`Meta`, `Shift`, `Alt`/`Option`.
Комбинируйте их знаком `+`: `Ctrl+Shift+V`. Последняя часть должна быть одной
буквой/цифрой/знаком либо именем клавиши: `Esc`/`Escape`, `Tab`, `Backtab`,
`Enter`/`Return`, `Space`, `Backspace`, `Delete`, `Up`, `Down`, `Left`, `Right`,
`Home`, `End`, `PageUp`, `PageDown`. F1 и многоклавишные последовательности
вроде `gg` в этих полях не поддерживаются. Литералы `+` и `,` служат разделителями
и не задаются как отдельная клавиша. Для обратного Tab используйте `Shift+Tab`.

Указывайте варианты для русской и английской раскладок явно, как в стандартных
значениях. Алфавит меток не переводит привязки автоматически. На macOS для
предпросмотра чата используется физический Ctrl; Cmd+V сохраняет штатную вставку.
Некоторые другие команды исторически допускают эквивалентные модификаторы
Ctrl/Cmd: полная независимость этих модификаторов для всех команд не гарантируется.

Контекстные команды (например, `viw`, `y` в visual, `h/l` на ползунке, навигация
медиапросмотрщика) не превращаются в отдельные JSON-параметры. Совпадения
сочетаний допустимы: действие зависит от активного окна, поля и режима.
Не назначайте нескольким действиям одну клавишу в одном контексте, если
не хотите зависеть от приоритета обработчиков.

## Клавиатура редактора

В JSON-редакторе буквы, включая j/k/f/v, вводятся как текст. Cmd+V на macOS
вставляет JSON; Cmd+A выделяет документ; Cmd+Z отменяет правку текста, а не
настройки, уже сохранённые кнопкой «Применить». Tab/Shift+Tab переводят фокус
между вкладками, редактором и кнопками. Enter в редакторе добавляет строку,
Enter на кнопке выполняет её действие. Отступы в JSON можно вводить пробелами.
Номера строк не входят в текст и не попадают в буфер обмена. Подсветка помогает
различать ключи и значения, но не заменяет проверку кнопкой «Применить».
Длинные строки не переносятся: прокручивайте по горизонтали трекпадом либо
нижней полосой прокрутки. Вертикальная полоса прокручивает документ.

## Справочник всех ключей

### `vim-keymap`

UI: **Vim keymap**.

Включает Vim-навигацию. false отключает Vim-обработчики, но не удаляет остальные настройки. Поля ввода сохраняют обычный набор текста.

Тип: `boolean`. Значение по умолчанию и пример:

```json
{
    "vim-keymap": true
}
```

### `vim-keymap-escape-closes-composer`

UI: **Vim Esc closes composer state**.

Разрешает Esc сначала отменить ответ, редактирование, пересылку и другое временное состояние редактора сообщения, а затем менять режим Vim. Отдельные привязки отмены ответа и редактирования действуют независимо от этого переключателя.

Тип: `boolean`. Значение по умолчанию и пример:

```json
{
    "vim-keymap-escape-closes-composer": true
}
```

### `vim-keymap-scroll-step`

UI: **Vim scroll step**.

Шаг одиночного нажатия клавиши прокрутки, в пикселях. Относится к чату и прокручиваемым модалкам; содержимое, которое помещается целиком, прокручивать некуда.

Тип: `integer`. Диапазон: 80–1800. Значение по умолчанию и пример:

```json
{
    "vim-keymap-scroll-step": 180
}
```

### `vim-keymap-hold-scroll-speed`

UI: **Vim hold scroll speed**.

Скорость удерживаемой прокрутки чата, в пикселях в секунду. Не является длительностью анимации или шагом одиночного нажатия.

Тип: `integer`. Диапазон: 600–16000. Значение по умолчанию и пример:

```json
{
    "vim-keymap-hold-scroll-speed": 3200
}
```

### `vim-keymap-hint-size`

UI: **Vim hint letter size**.

Размер шрифта буквенных подсказок, в пунктах QFont. Большие значения требуют больше места возле целей.

Тип: `integer`. Диапазон: 10–24. Значение по умолчанию и пример:

```json
{
    "vim-keymap-hint-size": 13
}
```

### `vim-keymap-hint-alphabet`

UI: **Vim hint buttons language**.

Алфавит меток: russian: русские буквы, english: латинские буквы и знаки. Не меняет раскладку клавиатуры или привязки команд. Метки удлиняются только при нехватке коротких.

Тип: `string`. Допустимые значения: `russian`, `english`. Значение по умолчанию и пример:

```json
{
    "vim-keymap-hint-alphabet": "russian"
}
```

### `vim-keymap-compose-cursor-style`

UI: **Vim compose cursor style**.

Форма курсора в поле сообщения в режиме просмотра: block: блок символа, bar: вертикальная черта, underline: подчёркивание. Не меняет системный курсор в режиме ввода.

Тип: `string`. Допустимые значения: `block`, `bar`, `underline`. Значение по умолчанию и пример:

```json
{
    "vim-keymap-compose-cursor-style": "block"
}
```

### `vim-keymap-compose-cursor-width`

UI: **Vim compose cursor width**.

Ширина курсора поля сообщения, в пикселях. Блочный курсор подстраивается под символ; эта величина не задаёт ширину букв текста.

Тип: `integer`. Диапазон: 1–30. Значение по умолчанию и пример:

```json
{
    "vim-keymap-compose-cursor-width": 5
}
```

### `vim-keymap-compose-cursor-height`

UI: **Vim compose cursor height**.

Высота курсора поля сообщения, в процентах высоты строки. Не изменяет размер самого текста.

Тип: `integer`. Диапазон: 20–100. Значение по умолчанию и пример:

```json
{
    "vim-keymap-compose-cursor-height": 100
}
```

### `vim-keymap-compose-cursor-blink`

UI: **Vim compose cursor blink**.

Интервал мигания курсора поля сообщения, в миллисекундах. 0 отключает мигание и оставляет курсор видимым постоянно.

Тип: `integer`. Диапазон: 0–2000. Значение по умолчанию и пример:

```json
{
    "vim-keymap-compose-cursor-blink": 0
}
```

### `vim-keymap-key-toggle-mode`

UI: **Vim key: toggle mode**.

Переключение режима ввода и режима просмотра. Esc сначала обрабатывает открытые подсказки, вложенные окна и отмену состояния редактора; это не безусловное закрытие всего интерфейса.

Тип: `string`. Сочетания клавиш; пустая строка отключает команду. Значение по умолчанию и пример:

```json
{
    "vim-keymap-key-toggle-mode": "Esc"
}
```

### `vim-keymap-key-cancel-reply`

UI: **Vim key: cancel reply**.

Отмена текущего ответа на сообщение. При назначении Esc отмена ответа имеет приоритет перед переключением режима.

Тип: `string`. Сочетания клавиш; пустая строка отключает команду. Значение по умолчанию и пример:

```json
{
    "vim-keymap-key-cancel-reply": "Esc"
}
```

### `vim-keymap-key-cancel-edit`

UI: **Vim key: cancel edit**.

Отмена редактирования отправленного сообщения. Пустая строка отключает отдельную команду, но общий переключатель обработки Esc может по-прежнему отменять редактирование.

Тип: `string`. Сочетания клавиш; пустая строка отключает команду. Значение по умолчанию и пример:

```json
{
    "vim-keymap-key-cancel-edit": ""
}
```

### `vim-keymap-key-help`

UI: **Vim key: help**.

Открывает краткую справку по командам Vim и журнал последних клавиш. Полное руководство находится в файле docs/vim-keymap.md и Wiki проекта.

Тип: `string`. Сочетания клавиш; пустая строка отключает команду. Значение по умолчанию и пример:

```json
{
    "vim-keymap-key-help": "?"
}
```

### `vim-keymap-key-scroll-down`

UI: **Vim key: scroll down**.

Прокрутка вниз в режиме просмотра. В модалках действует вне редактируемых полей независимо от режима чата за окном. В поле ввода j остаётся буквой.

Тип: `string`. Сочетания клавиш; пустая строка отключает команду. Значение по умолчанию и пример:

```json
{
    "vim-keymap-key-scroll-down": "j, о"
}
```

### `vim-keymap-key-scroll-up`

UI: **Vim key: scroll up**.

Прокрутка вверх; правила режима и полей ввода такие же, как у прокрутки вниз.

Тип: `string`. Сочетания клавиш; пустая строка отключает команду. Значение по умолчанию и пример:

```json
{
    "vim-keymap-key-scroll-up": "k, л"
}
```

### `vim-keymap-key-jump-bottom`

UI: **Vim key: jump to bottom**.

Выполняет действие нижней угловой кнопки чата: переход к актуальной позиции или возврат по истории переходов. Это не просто прокрутка до конца загруженных сообщений.

Тип: `string`. Сочетания клавиш; пустая строка отключает команду. Значение по умолчанию и пример:

```json
{
    "vim-keymap-key-jump-bottom": "Ctrl+G, Ctrl+п"
}
```

### `vim-keymap-key-copy-message`

UI: **Vim key: copy message hints**.

Показывает метки для копирования сообщений. Выбранное сообщение копируется с учётом ограничений чата; фотографии копируются как изображение после загрузки. В выделенном тексте y имеет свою контекстную роль.

Тип: `string`. Сочетания клавиш; пустая строка отключает команду. Значение по умолчанию и пример:

```json
{
    "vim-keymap-key-copy-message": "y, н"
}
```

### `vim-keymap-key-select-message-text`

UI: **Vim key: select message text hints**.

Показывает метки текстовых сообщений. После выбора можно двигаться по тексту без ввода, включить visual клавишей v и скопировать выделение клавишей y.

Тип: `string`. Сочетания клавиш; пустая строка отключает команду. Значение по умолчанию и пример:

```json
{
    "vim-keymap-key-select-message-text": "Ctrl+Shift+V, Ctrl+Shift+м"
}
```
