# Сборка пакетов Telegravim

Windows x64 и Linux x86_64 собираются вручную через GitHub Actions:
`Windows release package` и `Linux release package`. Выберите проверенный ref
через **Run workflow**. Для стабильного релиза используйте точный итоговый
коммит `main` после PR `develop` → `main`, как описано в
[правилах веток](branch-flow.md). Сборка рабочей ветки не является релизом.

Workflow имеют только `contents: read` и требуют подтверждения владельца
через защищённое окружение `network-review`. Для сборки используются приватные
`TELEVIM_API_ID` и `TELEVIM_API_HASH` из GitHub Secrets; они не должны попадать
в исходники, журналы и метаданные пакетов. Workflow не отправляют уведомления,
не создают теги и не публикуют релиз. Готовые архивы с контрольными
суммами сохраняются в Actions artifacts на 14 дней. `BUILD-INFO.json` внутри
пакета фиксирует версию, коммит, платформу и конфигурацию Release.
Поле `source_ref` позволяет явно указать SHA исходников, в том числе итоговый
коммит `main` при повторном использовании кэша рабочей ветки. Если поле пустое,
собирается ref самого workflow. Проверяйте `commit` в `BUILD-INFO.json`.

Linux использует официальный образ сборочных зависимостей Telegram,
закреплённый по digest, и проверяет сборку вместе с нативными Vim-тестами.
Windows использует GitHub-hosted `windows-2022`, Visual Studio 2022, x64 MSVC,
Qt 6 и штатный
`prepare/win.bat`; зависимости сохраняются в кэше по содержимому скриптов
подготовки. При пустом кэше первая сборка существенно дольше повторных.

Автообновление официальным Telegram и автоматическая отправка crash reports
отключены, как в локальном macOS-пакете. Пакеты включают лицензии словарей.
Нативные тесты не заменяют проверку входа, переписки и интерфейса на реальном
аккаунте. Отмечайте эти проверки отдельно в описании опубликованного релиза.

macOS ARM64 DMG собирается через workflow `macOS release package` из точного
коммита `main`, переданного полным SHA в `source_sha`. Workflow также требует
подтверждения `network-review` и приватных API-параметров. Он выполняет Release,
strip, подпись с entitlements, проверки codesign и `hdiutil verify`, затем
сохраняет DMG, контрольную сумму и `source.json` в Actions artifacts.
Локальная сборка из того же коммита остаётся доступной с теми же проверками.
