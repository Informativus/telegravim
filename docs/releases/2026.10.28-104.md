# Telegravim 2026.10.28-104

Кандидат общего выпуска Desktop и Televim для Android. Публикация ожидает
завершения интеграции, сборок и проверки переноса на реальном телефоне.

## Televim для Android

Полноценный клиент на основе Telegram Android 13.1.1 находится в той же
монорепе, что и Desktop. Приложение имеет собственный идентификатор
`org.informativus.televim` и постоянный ключ подписи. Установка не заменяет
официальный Telegram.

Первый импорт переносит два параметра: отправку сообщений клавишей Enter
и крупные эмодзи. Они применяются ко всем аккаунтам Android-приложения.
Другие модули Desktop из полного архива сохраняются зашифрованными и
не активируются; это не перенос всех возможностей Desktop на телефон.

## Перенос настроек без сети

1. На Desktop откройте **Settings → Advanced → Transfer local data →
   Transfer settings to Android** и выберите параметры.
2. Задайте отдельный пароль экспорта и создайте QR-код или ссылку
   `televim://`. Пароль не включается в ссылку.
3. На Android откройте **Import desktop settings**. Отсканируйте QR-код
   либо вставьте ссылку; также можно открыть ссылку непосредственно в Televim.
4. Введите пароль экспорта, просмотрите изменения и подтвердите применение.

В ссылке находится сам зашифрованный пакет. Сервер передачи, соединение
между устройствами и загрузка по URL не нужны. QR распознаётся на телефоне.
Обычная переписка Telegram по-прежнему использует сеть.

Для передачи файлом сохраните зашифрованный `.tgv` или JSON с выбранными
параметрами. JSON не зашифрован и не требует пароля. В системном файловом
менеджере Android откройте локальный файл через **Open with → Televim**;
для `.tgv` доступно также **Share → Televim**. Облачные, виртуальные и
неподдерживаемые источники отклоняются. Сессии Telegram, пароли аккаунтов
и приватные ключи чатов в экспорт настроек не включаются.

[Формат и ограничения импорта](../android/offline-import.md).

## Desktop

Выпуск сохраняет накопленные изменения Vim-навигации, локальные папки,
закрепления, теги Избранного, быстрые ответы и локальную транскрипцию.
В настройках Telegravim сгруппированы управление клавиатурой, локальные
возможности и параметры чтения.

Необязательный режим локальной диктовки добавляет текст в цикл записи
голосового/видеосообщения. После записи можно проверить и отредактировать
текст, затем явно выбрать отправку текста или аудио. Закрытие просмотра
отменяет распознавание и ничего не отправляет.

## Пакеты

| Система | Файл | Установка |
| --- | --- | --- |
| macOS, Apple Silicon | `Telegravim.dmg` | Откройте образ и перенесите приложение в Applications. |
| Windows x64 | `Telegravim-windows-x64.zip` | Распакуйте папку целиком и запустите `Telegram.exe`. |
| Linux x86_64 | `Telegravim-linux-x86_64.tar.xz` | Распакуйте архив и запустите `Telegravim/Telegram`. |
| Android 8+, ARM64 | `Televim-android-arm64-v8a.apk` | Откройте APK на телефоне и разрешите установку из выбранного источника. |

Контрольные суммы публикуются в `SHA256SUMS.txt`. Все пакеты общего релиза
должны происходить из одного итогового коммита `main`; промежуточный
Actions artifact не является опубликованным релизом.

macOS-пакет использует ad-hoc подпись без нотариализации Apple.
Windows-пакет не имеет подписи издателя. APK подписан постоянным ключом
Televim. Обновления устанавливаются вручную со страницы GitHub Releases;
автоматическое обновление официальным Telegram отключено.

## Проверки перед публикацией

До публикации необходимо завершить сборки из итогового коммита, проверить
подписи, контрольные суммы и метаданные пакетов. Проверка реального телефона
должна подтвердить установку, QR и импорт, пароли Unicode, сохранение
параметров после перезапуска и отсутствие запросов, вызванных импортом.
Проверки исходников и компиляция не заменяют эти наблюдения.
